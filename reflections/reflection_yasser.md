# Final Reflection

## What I learned about backend development
I learned how backend systems connect APIs to databases using Node.js, Express.js, and MySQL. I also learned how routes, middleware, authentication, and database queries work together in a backend application.

## What I learned about working with a shared codebase
I learned the importance of organizing files clearly and using GitHub commits to track changes. Keeping code structured made it easier to improve the project over time.

## One technical challenge I solved
One challenge I solved was implementing JWT authentication and protecting routes using middleware. I also fixed issues related to request validation and error handling.

## One area I would improve with more time
If I had more time, I would improve reservation conflict detection and add more advanced validation and scheduling features.

## How this project represents my skills professionally
This project demonstrates my ability to build and organize a backend API with authentication, middleware, database integration, and RESTful routes using professional development tools.
